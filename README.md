One funny single-line excuse a developer gives when code breaks in production — the funniest one we could think of.

> I reverted the change. The revert is what broke it. The change was load-bearing.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`. See `METHOD.md` for how the line was chosen: 30 candidates, single-elimination tournament against the published judge criteria.
